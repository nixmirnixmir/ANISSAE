# ANISSAE (Analyzing Number Iterations for Solving Systems of Algebraic Equations)
Приложение на C# (WPF) для анализа количества итераций, необходимых для решения системы линейных алгебраических уравнений методами Якоби и Зейделя, при заданной точности.
## Стек технологий
- Язык: C# (.NET Framework 4.7.2)
- GUI: WPF (XAML)
- Система сборки: Visual Studio
## Функциональность

### Основные возможности
- **Сравнение методов** по числу итераций
- **Автоматическая генерация** матриц любой размерности для тестирования
- **Визуализация** зависимости числа итераций от точности
- **Визуализация** зависимости числа итераций от начального приближения
- **Вычисление нормы невязки** для решения, полученного методом Якоби
- **Расчёт критерия сходимости** — среднее отношение суммы модулей недиагональных элементов к диагональному

### Формат входных данных
Файл `input.txt` должен содержать:
- e # точность
- n # размерность матрицы
- A11 A12 ... A1n b1 # первая строка матрицы и соответствующий ей свободный член
- A21 A22 ... A2n # вторая строка матрицы и соответствующий ей свободный член
- ... # последующие строки матрицы и соответствующие им свободные члены

### Формат входных данных
Файл `output.txt` содержит список решений системы линейных алгебраических уравнений вида x_i = y, где i-номер неизвестной, а y - её значение.

### Основные выводы
1. График зависимости точности от числа итераций напоминает ветвь гиперболы.
2. Минимальное количество итераций можно получить при использовании начального приближения, равного 1. Сам график имеет вид, похожий на √(|kx – 1|).
3. При решении систем уравнений, удовлетворяющих достаточному условию сходимости метода Якоби, количество итераций в среднем не превышало 20. Количество итераций значительно уменьшается, если отношение суммы модулей недиагональных элементов строки к модулю диагонального элемента превышает 0,4.
4. Метод Зейделя позволяет вычислить переменные системы линейных алгебраических уравнений в случае, если метод Якоби этого сделать не может.
